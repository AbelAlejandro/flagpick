# Flagpick

Flagpick is an interactive `--help` for every CLI: local, offline, and it never executes your command.

Development is tracked in [Linear](https://linear.app/comply-finops/issue/COM-62/deliver-flagpick-v1-from-the-approved-product-specification). The approved product brief is in [`flagpick-product-engineering-spec.md`](flagpick-product-engineering-spec.md).
